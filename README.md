Channel Sales Dashboard — Data Input Workbook					
					
					
HOW THIS WORKS					
1. Edit the yellow cells in the 'Zones' and 'ASM Roster' tabs with your real numbers.					
2. Save this file (keep it as .xlsx).					
3. Open Channel_Sales_Dashboard.html and ASM_Performance_by_Zone.html in your browser.					
4. Click the 'Upload Data (Excel)' button in the header of each page and select this file.					
5. The dashboard redraws instantly using your data — nothing is uploaded to any server, it all happens in your browser.					
6. Whenever you update numbers here, just re-upload the file to refresh the dashboard.					
					
SHEETS IN THIS WORKBOOK					
- Zones: one row per zone (7 rows). All NBD, CRR, billing, target, headcount, and open-order figures live here.					
- ASM Roster: one row per individual ASM. Each ASM's Collection and Target roll up into their zone's ranking on the ASM Performance page.					
					
IMPORTANT RULES					
- Do NOT rename, delete, or reorder the column headers in row 1 of either sheet -- the dashboard reads columns by name.					
- Do NOT rename the Zone values (East, North 1, North 2, West, NCR, South, Central) -- they must match exactly between both sheets.					
- Zone in the ASM Roster sheet must match one of the 7 zones in the Zones sheet exactly (case-sensitive).					
- All money figures are in Rs. Lakhs (L). Blue-tinted columns are auto-calculated (Total Collection, Target Achievement %, Achievement %) -- you do not need to fill those in, just the yellow input columns.					
- You can add or remove ASM rows freely in the ASM Roster sheet -- the dashboard will pick up however many rows exist per zone.					
- Yellow-filled cells are the ones you should edit. Column headers and sheet structure should stay as-is.
